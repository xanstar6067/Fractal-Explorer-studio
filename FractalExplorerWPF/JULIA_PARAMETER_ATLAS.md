# Атлас параметров семейства Жюлиа

Атлас поддерживает все 61 вариацию семейства Жюлиа в `MandelbrotWindow`, включая
Multijulia, Симоноброт с инверсией, отражённые полиномы и конструктор гибридов.
Доступность определяется общим `MandelbrotVariantDefinition.IsJulia` /
`HasJuliaConstant`, без отдельного списка вариантов. Название окна и заголовок
показывают выбранный вариант. Нового пункта каталога и нового формата сохранений нет.

## Управление

- Кнопка с пиктограммой сетки 3×3 расположена рядом с кнопкой скрытия меню на полотне,
  имеет тот же размер 34×34 и подсказку «Атлас параметров». Цвет следует текущей теме;
  доступное имя задано через `AutomationProperties.Name`. Доступна и при скрытой панели.
  Повторное нажатие активирует открытое окно атласа.
- По горизонтали меняется Re(C), по вертикали снизу вверх — Im(C). Начальный
  диапазон шириной 0.4 по обеим осям окружает текущую C; поддерживаемые границы
  −10…10. Значения вводятся через `NumericInput`, пары проверяются совместно.
- «Построить» рассчитывает сетку 3×3, 5×5 или 7×7. «Общий диапазон» соответствует
  карте выбора C: для классического Жюлиа Re(C) ∈ [−2; 1], Im(C) ∈ [−1.2; 1.2],
  для горящего корабля — [−2; 1.5] и [−1; 1.5], для остальных — [−2; 2] и [−1.5; 1.5].
- Щелчок выделяет ячейку и показывает её миниатюру крупнее и точные значения C.
  «Исследовать рядом» вдвое сужает диапазоны вокруг неё, сохраняя историю.
  «Назад к диапазону» возвращает предыдущие границы.
- «Применить в текущем окне» и двойной щелчок обновляют только C исходного окна:
  текстовые поля, маркер карты и новый кадр. Центр, глубокий масштаб, итерации,
  палитра, окрашивание, степень, инверсия и последовательность гибрида сохраняются.
  Атлас остаётся открыт для повторного выбора.
- «Остановить» прекращает расчёт; готовые ячейки остаются доступны. Новое построение
  отменяет старое. Закрытие владельца закрывает атлас и отменяет расчёт.

## Рендер и ограничения прототипа

Используется существующий `MandelbrotFamilyRenderer`, без новой формулы или шейдера.
Каждая миниатюра 144×108, центр (0; 0), зум 0.8; общая палитра и параметры окраски
копируются при открытии атласа вместе с вариантом, степенью, инверсией и гибридной
последовательностью. Изменение формулы в исходном окне (включая загрузку состояния)
обновляет открытый атлас и перестраивает показанный диапазон, не завершая черновики
полей диапазонов. Каждое поколение считает все ячейки по собственному снимку формулы.
Число итераций ограничено 250 для быстрого обзора,
фактическое значение указано в статусе. Поэтому детали превью могут отличаться от
полного кадра. Увеличенный просмотр использует ту же миниатюру.

Сначала готовится центральная ячейка. Все ячейки считаются последовательно одним
потоком ЦП, включая случаи частого перестроения: общий семафор не допускает наложения
задач. Публикация проверяет отмену и актуальность запроса; старый кадр не заменяет
новый выбор. В главном окне работающий рендер остаётся самостоятельным.

Состояние перед расчётом копируется: обзорный вид и выбранная C не изменяют исходный
DTO. Атлас не создаёт пользовательские файлы. Оболочка `Views/ParameterAtlasWindow.xaml`
и `.xaml.cs` общая с атласом Phoenix 2D: история, выбор, расчёт поколений и отмена.
`Views/JuliaParameterAtlasWindow.cs` подключает формулу Жюлиа; модель диапазона и
адаптер рендера общие для всех его вариантов. Параметрические варианты Мандельброта
атлас не открывают. Дополнительные селекторы осей и поля фиксированных компонент
в атласе Жюлиа скрыты, поскольку у него только две компоненты C.

## Проверка

```powershell
dotnet build .\FractalExplorerWPF\FractalExplorerWPF\FractalExplorerWPF.slnx
dotnet run --project .\FractalExplorerWPF\Verification\SavePreviewVerification.csproj -- julia-atlas
```

Адресная группа без показа окон: оси и границы, разные C и неизменность исходного
состояния, отмена, устаревшие поколения, наличие пиктограммы и правильного заголовка
у всех вариантов Жюлиа, доступность при скрытом меню, числовые черновики и запятая,
выбор реальной кнопкой, применение через событие владельцу без нового окна и потери
точного центра/зума. Для всех вариантов проверяется только маленький кадр 32×24 и
сохранение формулы при применении C. Для Multijulia, Симоноброта и гибрида проверяется
обновление формулы уже открытого атласа и неизменность формулы незавершённого поколения.
Тесты сохранений вариантов и тяжёлые семейные группы для этой задачи не нужны.

Ручная проверка: открыть классическое и модифицированное Жюлиа, скрыть меню, открыть атлас; выбрать
3×3/5×5/7×7, изменить границы, уточнить ячейку и вернуться назад. Применить C кнопкой
и двойным щелчком; убедиться, что изменилось исходное окно. Быстро запустить несколько
построений, остановить и закрыть окно во время расчёта. Изменить степень Multijulia,
инверсию Симоноброта и шаги гибрида при открытом атласе. Проверить пиктограмму в текущей теме.
