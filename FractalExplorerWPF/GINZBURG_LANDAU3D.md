# Гинзбург–Ландау 3D · комплексное поле

WPF-каталог: **Динамические системы и хаос → Пространственные системы**.
Ключ запуска `Fractal3D:GinzburgLandau3D`; окно — общее `Fractal3DWindow`.

## Модель

Безразмерное кубическое комплексное уравнение Гинзбурга–Ландау:

```text
∂ₜA = A + (1 + i c₁)∇²A − (1 + i c₃)|A|²A,
A = u + i v.
```

`c₁` задаёт дисперсию пространственной связи, `c₃` — нелинейную частоту.
Вещественная часть диффузии и линейный рост нормированы на единицу.
Это модель пространственных колебаний; электромагнитное поле и уравнения
сверхпроводимости с калибровочной связью здесь не моделируются.
Источники: [обзор Aranson–Kramer](https://arxiv.org/abs/cond-mat/0106115),
[динамика трёхмерных вихревых нитей](https://arxiv.org/abs/patt-sol/9712004).

Сетка кубическая, 32–128 узлов по каждой оси, включая размеры, не кратные группе шейдера.
Длина физической области — `N·Δx`; изменение сетки при том же Δx меняет размер области.
Границы: периодические либо нулевая нормальная производная (краевой сосед равен крайнему узлу).
Поле содержит действительную и мнимую компоненты float32; угол не хранится как состояние.

## Численная схема и ограничения

Один шаг: точная локальная реакция Δt/2, явная диффузия Δt, точная реакция Δt/2.
Для локальной реакции, с τ = Δt/2:

```text
D = 1 + |A₀|²·(exp(2τ)−1)
A(τ) = A₀·sqrt(exp(2τ)/D)·exp(−i c₃·log(D)/2).
```

Диффузия использует семиточечный лапласиан. Схема имеет первый порядок по времени
(явный шаг диффузии) и второй по пространству. Амплитуда не обрезается для стабилизации.
Проверка `Δt·(1+c₁²)/Δx² ≤ 0,15` оставляет запас относительно границы 1/6,
при которой явная комплексная диффузия перестаёт быть сжимающей в норме L₂.
Диапазоны: c₁/c₃ −3…3, Δx 0,5…2, Δt 0,0005…0,05.
Это проверка устойчивости, а не гарантия точности: для тонких ядер уменьшайте Δx
и соответственно Δt, сравнивайте с меньшим шагом времени.

Вычисление — наследник `GpuVolumeSimulation`, три GPU-прохода на шаг, общая очередь Direct3D 11.
Поле не считывается на ЦП между кадрами. Два слота публикации удерживают показанный кадр
при расчёте следующего; отмена прекращает подачу целых шагов между порциями.
Все четыре вычислительных прохода и пиксельный шейдер входят в общий дисковый кэш
и команду «Пересобрать шейдеры».

## Поле, отображение и управление

Начальные поля: вихревое кольцо, прямая нить, пара противоположных вихрей,
воспроизводимое беспорядочное поле, фазовая волна и однородное поле.
Шесть готовых видов показывают эти структуры, дефекты амплитуды и фазу на срезе.
Затравки вихрей — начальные приближения, а не точные стационарные решения.
По умолчанию кольцо проходит 400 шагов подготовки и встаёт на паузу.

- **Вихревые нити:** ненулевой оборот фазы ±2π вокруг хотя бы одной из трёх граней ячейки.
  Нулевые вершины с неопределённой фазой не удостоверяют вихрь. Это дискретный индикатор
  с толщиной порядка узла сетки, а не извлечённая непрерывная центральная линия.
- **Дефекты амплитуды:** плотность `max(0,1−|A|)`; низкая амплитуда не обязательно имеет заряд.
- **Амплитуда:** плотность `|A|`, полезна вместе со срезом или прозрачным стилем «Плотность».
- **Окраска по фазе:** угол A, циклическая палитра; при интерполяции используются cos/sin,
  чтобы избежать искусственного шва на ±π. В самом ядре фаза физически не определена.
- **Окраска по амплитуде:** |A|; общие свет, девять стилей, камера и зонд работают с выбранной плотностью.

Уравнение, сетка и затравка — черновик до «Применить и начать заново».
Неверный ввод сохраняет показанное поле. Вид, уровень поверхности, срез и скорость кадров
меняются без сброса времени. Пробел — продолжить/пауза; «Один кадр» — заданное число шагов.
Камера, палитра, сохранения и экспорт общие с другими 3D-режимами.
Во время подготовки показывается общий экран; остановка оставляет пригодное частичное поле.

Кисть в центре или Shift+щелчок на выбранном срезе: плавно погасить амплитуду
либо сдвинуть фазу до π, сохраняя амплитуду. На периодических границах кисть оборачивается.
Кисть не продвигает время; погашенная область сама по себе не гарантирует вихревое кольцо.

## Сохранение и файлы

`Saves/Fractal3DGinzburgLandau/`: стандартный JSON и PNG-превью через `Fractal3DSaveStore`.
Показанное комплексное поле и номер шага сохраняются без потерь как Brotli/base64 float32
с ограничением распакованного размера. GPU-объекты в JSON не попадают.
Продолжение на том же ГП побитово совпадает; другой драйвер может округлять иначе.
Старые сохранения остальных режимов не требуют миграции: новое поле параметров имеет умолчание.
Облачный репозиторий распознаёт категорию; общий предел сервера 1 МиБ на JSON
сохраняется, поэтому большие контрольные точки могут сохраняться только локально.

Основные файлы:
`Models/GinzburgLandau3DSettings.cs`, `Models/Fractal3DModes/GinzburgLandau3DMode.cs`,
`Controls/GinzburgLandau3DEditor.xaml(.cs)`, `Core/Rendering3D/GinzburgLandau3DGpuSimulation.cs`,
`GinzburgLandau3DComputeShader.cs`, `Shaders/Volume.hlsl`,
`Infrastructure/Serialization/GinzburgLandau3DFieldConverter.cs`.

## Проверка

```powershell
dotnet build .\FractalExplorerWPF\FractalExplorerWPF\FractalExplorerWPF.slnx
dotnet run --project .\FractalExplorerWPF\Verification\SavePreviewVerification.csproj -- ginzburg-landau3d [папка PNG]
```

Группа проверяет независимый расчёт Complex/double, обе границы, аналитическую локальную
реакцию и сходимость фазовой волны при уменьшении Δt, вихри обоих знаков вдоль каждой оси,
отсутствие ложных нитей в нулевом и однородном поле, обе кисти через границу,
сетки 32/33/128, неизменность показанного слота, устаревшие билеты, отмену,
точность JSON/хранилища/продолжения, повреждённые данные, облачную категорию,
готовые виды с PNG, общие стили, срезы, зонд и скрытое WPF-окно.
Проверки перенаправляют пользовательские данные в отдельную папку.

Ручная проверка: открыть режим, дождаться кольца; запустить, остановить, сделать один кадр.
Переключить все готовые виды, источники цвета и срезы; проверить фазовую волну на срезе.
Сменить c₁/c₃, применить; ввести чрезмерный Δt и убедиться, что текущий кадр остаётся.
Применить обе кисти, включая Shift+щелчок на срезе; сохранить, изменить поле,
загрузить и продолжить. Экспортировать кадр со сглаживанием, проверить отмену;
после пересборки шейдеров снова открыть режим и готовые виды.
