# Тетраэдр Серпинского

WPF-режим `Fractal3DKind.SierpinskiTetrahedron` использует общий исследователь
`Fractal3DWindow`, GPU-оценку расстояния и общие камеру, оформление и сохранения.
Стартовый вид и пресеты — `Models/Fractal3DModes/SierpinskiTetrahedronMode.cs`.

Масштаб складывания меняется от 1.05 до 8; классический вариант имеет масштаб 2.
Итерации 1–64 задают глубину повторений. Масштаб 1.8 даёт сросшуюся форму,
большие значения могут разделять её на очень мелкие детали. Видимость деталей
зависит от камеры и разрешения кадра.

## Атлас параметров

Кнопка **«Атлас параметров тетраэдра…»** в блоке «Форма» открывает
`Views/SierpinskiAtlasWindow.cs`: масштаб складывания по горизонтали,
целое число итераций по вертикали. Начальный диапазон расположен вокруг
текущих значений, ширина — 0.4 по масштабу и 4 по итерациям.
«Общий вид» показывает полные допустимые диапазоны.

Общая оболочка `ParameterAtlasWindow` поддерживает сетки 3×3, 5×5 и 7×7,
уточнение вокруг выбранной плитки, историю диапазонов и остановку расчёта.
Если целых итераций в диапазоне меньше размера сетки, строки не повторяются.
Превью — последовательные GPU-кадры 144×108; число итераций берётся с оси
без ограничения 32, шаги луча ограничены 160, SSAA, мягкие тени и AO отключены.
Допуск попадания луча пересчитан для миниатюры.

Применение меняет только масштаб и итерации. Камера, окраска и качество
основного вида сохраняются. Закрытие без применения ничего не меняет.
Масштаб читается и загружается без округления; поля используют `NumericInput`.
Формат сохранений не изменён.

## Проверка

`dotnet run --project .\FractalExplorerWPF\Verification\SavePreviewVerification.csproj -- sierpinski-atlas`
проверяет границы, уникальные целые строки, 64 итерации в превью, прямой GPU-кадр,
изменение изображения, точное применение, сохранение/загрузку и закрытие во время расчёта.

Вручную: открыть атлас классического тетраэдра, сравнить масштабы 1.8–2.2,
уточнить интересный вариант, вернуться по истории, применить и сохранить вид.
Проверить закрытие атласа во время построения и диапазон 63–64 итерации.
