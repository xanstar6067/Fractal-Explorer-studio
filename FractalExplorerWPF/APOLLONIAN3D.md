# Аполлонова упаковка сфер

WPF-режим `Fractal3DKind.ApollonianPacking` работает в `Fractal3DWindow`.
Геометрия — конечные поколения взаимно касающихся сфер внутри внешней сферы,
которая сама не рисуется. Начальная конфигурация фиксирована. Параметр
«Поколения сфер» принимает целые значения 1–5; новые поколения заполняют
более мелкие промежутки. Есть четыре пресета и общие камера, навигация,
оформление, сохранения и экспорт трёхмерного окна.

Расчёт — `Core/Rendering3D/ApollonianSpherePacking.cs`: отражения конфигурации
пяти ориентированных сфер, исключение повторов и дерево охватывающих сфер.
Рендер — существующая ветвь `KIND_ApollonianPacking` в `Shaders/Fractal3D.hlsl`.
Определение режима и пресеты — `Models/Fractal3DModes/ApollonianPackingMode.cs`.

## Атлас поколений и окраски

Кнопка в `Controls/ApollonianPackingEditor` открывает
`Views/ApollonianPackingAtlasWindow.cs` через `Fractal3DWindow.ShapeAtlas.cs`.
По горизонтали — поколение 1–5, по вертикали — номер источника окраски
из подписанного списка справа. Номер выбирает пункт списка; сходство номеров
не означает сходства цветов. Подписи ячеек и подсказки показывают названия
источников, принятые в основной панели этого режима.

Атлас берёт все источники через `Fractal3DMode.HasColoringMode`.
Специальные источники: диаметр, положение, масштаб и радиус сферы;
также доступны общие материал, нормаль, глубина и остальные источники рендера.
Геометрия при смене окраски остаётся той же.

Камера, палитра, её повтор, масштаб/сдвиг, цвет материала и стиль освещения
одинаковы для всех миниатюр. Применение меняет только `Iterations`
и `ColoringMode`, синхронизируя список окраски и видимость её настроек.
Остальные параметры и качество основного окна сохраняются.
Формат JSON и категория `Saves/Fractal3DApollonian` прежние.

Общая оболочка `ParameterAtlasWindow` предоставляет сетки 3×3/5×5/7×7,
целые диапазоны без повторов, NumericInput, общий диапазон, уточнение,
историю и отмену. Если целых значений мало, строк/колонок меньше размера сетки.
Общий последовательный GPU-источник `Fractal3DParameterAtlasWindow` ограничивает
изображение до 144×108, SSAA=1, без мягких теней/AO, с ограниченным бюджетом
шагов луча. Выбранное поколение не сокращается. Мелкие сферы нужно сверять
в основном окне. Закрытие/остановка не применяет выбор.
Новых вариантов шейдера нет: используется существующий общий дисковый кэш.

## Проверка

```powershell
dotnet build .\FractalExplorerWPF\FractalExplorerWPF\FractalExplorerWPF.slnx
dotnet run --project .\FractalExplorerWPF\Verification\SavePreviewVerification.csproj -- apollonian-packing-atlas
```

Адресная группа проверяет четыре пресета, все источники окраски и поколения,
границы и целочисленность, точность неизменённых полей, атомарный отказ.
Две малые GPU-сетки сверяются с прямым рендером; проверяются подписи,
применение, основная панель, сохранения/загрузка и закрытие во время построения.
Данные изолированы.

Вручную: сравнить поколения 1–5; выбрать материал, затем окраску по диаметру;
проверить сохранность камеры и палитры, видимость настроек окраски,
сохранение/загрузку и закрытие атласа без применения.
