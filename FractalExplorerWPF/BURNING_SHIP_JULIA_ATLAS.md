# Атлас параметров «Горящий корабль 3D — Жюлиа»

WPF → **Горящий корабль 3D — Жюлиа** → блок «Форма» → **«Атлас параметров C / степени…»**.
Показывает сетку динамических 3D-форм. Существующая карта выбора C на исходном корабле
доступна отдельно. Формула выбирается в основном окне до открытия атласа:
кватернионная с двумя/тремя отражениями или сферическая с двумя/тремя отражениями.
В атласе формула фиксирована; её название указано в пояснении справа.

## Управление

- Любые две оси из Cx, Cy, Cz и степени n. Остальные два значения фиксированы.
  По умолчанию Cx по горизонтали, Cy по вертикали. Дублирующие оси меняются местами.
- C от −8 до 8; степень — **целое число 2–16**, как в основном окне.
  Фиксированная степень и границы её оси завершаются через NumericInput:
  дробный ввод восстанавливается с объяснением, выход за пределы ограничивается.
- Стартовый диапазон вокруг текущего значения имеет ширину 0,4 для C и 2 для степени,
  у краёв сдвигается внутрь допустимых пределов. «Общий диапазон» — C от −2 до 2,
  степень от 2 до 16.
- Сетки до 3×3, 5×5 или 7×7, по умолчанию 3×3. Для степени выбираются **разные целые**
  значения, равномерно по диапазону с округлением. Если целых значений меньше размера
  сетки, колонок/строк меньше: диапазон 15–16 даёт две колонки или две строки.
  По Y максимум сверху. Дробные степени не попадают ни в расчёт, ни в подписи.
- Щелчок выбирает миниатюру, «Исследовать рядом» сужает диапазон; целые границы
  охватывают соседние степени. «Назад к диапазону» возвращает предыдущий охват.
  На самом узком диапазоне степень уже не уточняется, но C можно уточнять дальше.
- Применение или двойной щелчок меняет только C и степень, закрывает атлас,
  обновляет основной кадр и миниатюру карты выбора C. Формула, камера, свет,
  итерации, радиус вылета, палитра и качество сохраняются.
- Правка фиксированного значения блокирует прежний выбор. «Остановить» отменяет
  расчёт и сохраняет готовые ячейки. Закрытие без применения сохраняет исходный вид.

Пустая миниатюра возможна при выбранных параметрах; поиск не гарантирует непустоту форм.

## Реализация и данные

`Views/BurningShipJuliaAtlasWindow.cs` использует общий `Julia3DShapeAtlasWindow`
с Жюлиабульбом. Ограничения степени берутся из класса режима `PowerField`,
а `ParameterAtlasWindow` поддерживает целые оси и разные размеры по X/Y.
Область `ParameterAtlasRange` не ограничивает степень общим пределом ±10;
границы задаёт адаптер. Двумерные атласы сохраняют свои пределы −10…10.

Снимок сохраняет выбранную формулу, камеру и оформление. Миниатюры 144×108
строятся последовательно на ГП: до 32 итераций, до 160 шагов луча, SSAA=1,
без AO и мягких теней. Новые поколения отменяют прежние и защищены от запоздалых кадров.
`Fractal3DWindow.ShapeAtlas.cs` приостанавливает основной цикл и карту выбора C
на время модального окна; освобождение ресурсов ожидает текущий запрос ГП.
Неизменённые C сохраняют точность double; загрузка/применение записывают их без округления.

Используются существующие рендерер, шейдеры всех четырёх формул и общий дисковый кэш.
Формат сохранений, категория, начальный вид и пресеты не меняются.

## Проверка

```powershell
dotnet build .\FractalExplorerWPF\FractalExplorerWPF\FractalExplorerWPF.slnx
dotnet run --project .\FractalExplorerWPF\Verification\SavePreviewVerification.csproj -- burning-ship-julia-atlas
```

Проверяются четыре формулы против прямого GPU-рендера, все пары осей, целые степени
в размерах 3/5/7, две колонки и две строки без повторов, ввод, точность C,
поколения, применение только формы, сохранения, отмена и закрытие.
После изменения общей оболочки также проверяются `juliabulb-atlas`, `julia-atlas`,
`phoenix-atlas` и `numeric-input`. Проверки используют изолированные данные.

Вручную: выбрать каждую формулу и открыть атлас; сравнить Cx/Cy и степень/Cz;
проверить диапазон степени 15–16 и дробный ввод. Применить форму, проверить
сохранность формулы и камеры, обновление маркера карты; закрыть повторный атлас без применения.
