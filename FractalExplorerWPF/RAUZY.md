# Фрактал Раузи и плитки Трибоначчи

Каталог: **Математические лаборатории → Геометрия и преобразования → Фрактал Раузи · плитки Трибоначчи**.
Ключ запуска — `MathLab:Rauzy`; окно — общее `MathematicalLaboratoryWindow`.

## Модель

Классический случай — неподвижное слово подстановки `a → ab, b → ac, c → a`, начинающееся `abacaba…`.
Родственные варианты используют `a → a^k b, b → ac, c → a`, где `k = 1…4`.
Матрица подстановки имеет столбцы `(k,1,0)`, `(1,0,1)`, `(1,0,0)` и характеристический
полином `x³ − kx² − x − 1`. Его действительный корень β больше единицы, а комплексные
корни α и conj(α) лежат внутри единичного круга.

Префикс с количествами букв `(nₐ,nᵦ,n꜀)` отображается в комплексное число
`nₐ + nᵦ(α−k) + n꜀/α`. Это проекция на сжимающую плоскость, а не ортогональная
проекция на произвольно выбранную плоскость. Комплексные координаты могут отличаться
от других изображений поворотом или отражением. Цвет точки задаёт **следующая** буква слова:
получаются три под-плитки a/b/c. Точки до шага, а не после него, обеспечивают эту конвенцию.

Центральная плитка повторяется по решётке проекции целочисленной плоскости `x+y+z=0`:
`u = 1 − (α−k)`, `v = 1 − 1/α`. Мозаика — конечный участок из переносов `i·u+j·v`,
а не прямоугольная раскладка картинок. Контуры вычисляются по границе растровых меток;
это контуры конечного приближения, точность которых зависит от числа точек и масштаба.

Математика — `Core/Math/RauzyFractal.cs` (`Core.RauzyMath`, без UI).
Рендер — `Core/Rendering/Laboratories/RauzyLaboratory.cs` на `LaboratoryCanvas`.
Определение и стартовый вид — `Models/MathematicalLaboratoryModels.cs`.

Источники: [проекция и контрольные координаты SageMath](https://doc.sagemath.org/html/en/reference/combinat/sage/combinat/words/morphism.html#sage.combinat.words.morphism.WordMorphism.rauzy_fractal_projection),
[подстановки Пизо и связанные плитки](https://arxiv.org/abs/1907.11012).

## Управление

- **Режимы:** три под-плитки, отдельные a/b/c, периодическая мозаика, окраска по порядку построения.
- **Точек на кадр:** 100…2 000 000; по умолчанию 450 000. Для мозаики бюджет делится между
  копиями (не менее 100 точек на копию). Повышение бюджета уточняет то же слово.
- **Подстановка k:** 1 — Трибоначчи, 2…4 — родственные подстановки.
- **Радиус мозаики:** 1…4, только для мозаики; `(2r+1)²` копий.
- **Радиус точки:** 0,3…2,5 пикселя. Большая кисть заполняет разреженные участки, но сглаживает мелкую границу.
- **Заливка:** выключение оставляет контуры всех под-плиток и копий.
- **Направляющие:** затемняют границы; в мозаике показывают два вектора периода.
- **Анимация:** циклически увеличивает видимую длину префикса от 2% до 100%; образец постепенно уплотняется.
- Колесо — масштаб, ЛКМ — перемещение, поворот — поле панели; F11 — полный экран.
- Палитра — три цвета под-плиток и фон; в режиме порядка построения используется общая плавная палитра.

Сохранения используют `MathematicalLaboratorySaveStore` и каталог
`Saves/MathematicalLaboratory_Rauzy` через `AppPaths`. Сохраняются подстановка,
режим, бюджет, вид, цвета и фаза анимации. Случайности нет: тот же снимок даёт тот же кадр.
Превью каталога и PNG-экспорт используют общий рендер, отмена работает при генерации и рисовании.
Формат существующих лабораторий не меняется; новый пункт enum добавлен в конец.

## Проверка

```powershell
dotnet build .\FractalExplorerWPF\FractalExplorerWPF\FractalExplorerWPF.slnx
dotnet run --project .\FractalExplorerWPF\Verification\SavePreviewVerification.csproj -- rauzy --out <папка-PNG>
dotnet run --project .\FractalExplorerWPF\Verification\SavePreviewVerification.csproj -- laboratory
dotnet run --project .\FractalExplorerWPF\Verification\SavePreviewVerification.csproj -- catalog
```

`rauzy` проверяет неподвижность слова независимо от генератора, комплексные корни и собственный
вектор, координаты из SageMath, частоты Трибоначчи, стабильность префиксов, 24 кадра
(четыре подстановки × шесть режимов), контуры, анимацию, отмену и точный кадр после сохранения.
PNG — рендеры без открытия окон и захвата экрана.

Ручная проверка: открыть пункт каталога, переключить все режимы и k; проверить стыковку
мозаики и векторы, контуры, цвета, анимацию, масштаб/перемещение/поворот, сброс вида,
сохранение/загрузку и экспорт. Увеличивая масштаб, повышать число точек: изображение
является конечным облаком префиксов, произвольного глубокого зума здесь нет.

ScreenshotGen обнаруживает пункт через общий обход лабораторий: `--only=MathLab:Rauzy`,
файл `lab-rauzy.png`. Запускать только по запросу пользователя на скриншоты документации.
