# Атласы Мандельбульба и Мандельбокса

WPF → соответствующий 3D-режим → блок «Форма».

## Мандельбульб

Кнопка **«Атлас степени / итераций…»** открывает `MandelbulbAtlasWindow`.
Горизонталь — степень n (вещественная, −32…32), вертикаль — итерации (целые, 1…64).
Ограничения берутся из класса режима, как в основном окне. Начальные диапазоны
имеют ширину 2 по степени и 4 по итерациям вокруг текущего вида, с ограничением
у краёв. «Общий диапазон» показывает степени 2…16 и итерации 3…16.
Все миниатюры используют выбранное число итераций, включая 33…64.
При узком диапазоне целых значений строк меньше выбранного размера сетки,
повторяющихся строк нет. Применение меняет только степень и итерации.

## Мандельбокс

Кнопка **«Атлас параметров свёртки…»** открывает `MandelboxAtlasWindow`.
Любые два параметра можно назначить осям, третий остаётся фиксированным:

- масштаб свёртки −8…8;
- минимальный радиус инверсии 0,01…4;
- предел свёртки по кубу 0,1…8.

По умолчанию оси — масштаб и радиус. Начальная ширина диапазона масштаба 0,8,
радиуса и предела свёртки — 0,4. «Общий диапазон» охватывает допустимые пределы
выбранных осей. Назначение одинаковых осей меняет их местами.
Форма инверсии, вытяжение и округлость берутся из исходного вида и не меняются;
название формы показано в подсказке. Применение переносит три параметра свёртки.
Неизменённое фиксированное значение сохраняет полную точность исходного double.

## Общие команды

Сетка 3×3, 5×5 или 7×7; начальный размер 3×3. Щелчок выделяет вариант,
«Исследовать рядом» сужает диапазоны, «Назад к диапазону» возвращает предыдущие.
Применение кнопкой или двойным щелчком закрывает атлас и обновляет основной вид.
Камера, радиус вылета, палитра, свет и качество сохраняются.
Изменение фиксированного поля Мандельбокса блокирует старый выбор до перестроения.
Все числовые поля используют NumericInput; ошибочный ввод восстанавливается
или ограничивается с объяснением у поля. «Остановить» оставляет готовые миниатюры
доступными; закрытие без применения не меняет исходный вид.

Миниатюры 144×108 рассчитываются последовательно на ГП, от центра, с текущей камерой
и оформлением. Качество: до 160 шагов луча, SSAA=1, без AO и мягких теней;
детализация пересчитана на высоту миниатюры общим механизмом атласов. Для Мандельбокса
число итераций превью ограничено 32; применение сохраняет исходное полное число.
Пустые варианты и формы, выходящие за кадр, допустимы: камера автоматически не подбирается.

Общая связь — `Views/Fractal3DWindow.ShapeAtlas.cs`, оболочка — `ParameterAtlasWindow`,
превью — `Fractal3DParameterAtlasWindow`. Основной кадровый цикл приостановлен
на время модального атласа. Закрытие отменяет расчёт, ресурсы освобождаются после
завершения текущего GPU-запроса. Шейдеры, формат данных, пресеты и кэш прежние.

## Проверка

```powershell
dotnet build .\FractalExplorerWPF\FractalExplorerWPF\FractalExplorerWPF.slnx
dotnet run --project .\FractalExplorerWPF\Verification\SavePreviewVerification.csproj -- mandelbulb-atlas
dotnet run --project .\FractalExplorerWPF\Verification\SavePreviewVerification.csproj -- mandelbox-atlas
```

Адресные проверки: входы окна, NumericInput и разные границы параметров,
целочисленные строки 63/64 без повторов, пары осей Мандельбокса, точность,
миниатюра против прямого GPU-кадра, различие вариантов, применение только нужных
полей, JSON-сохранение/загрузка и закрытие во время расчёта. Данные изолированы.

Вручную: открыть каждый атлас, сравнить варианты, сузить диапазон и вернуться;
у Мандельбокса сменить оси и фиксированное значение, затем повторить с другой
формой инверсии. Применить вариант, проверить основной кадр и сохранение.
Повторно открыть, остановить расчёт и закрыть без применения.
