# Атлас параметров Жюлиабульба

WPF → Жюлиабульб → блок «Форма» → **«Атлас параметров C / степени…»**.
Атлас показывает динамические 3D-формы Жюлиабульба, а не карту принадлежности C.
Существующая 3D-карта выбора C на Мандельбульбе доступна отдельно.

## Управление

- Любые две оси из Cx, Cy, Cz и степени n; остальные два значения фиксированы.
  По умолчанию — Cx по горизонтали, Cy по вертикали. Дублирующие оси меняются местами.
- C ограничены −8…8, степень — −32…32, как в основном окне; дробные степени разрешены.
  Начальная ширина диапазона вокруг текущего значения: 0,4 для C, 2 для степени.
  У границы диапазон сдвигается внутрь допустимых пределов. «Общий диапазон» — C от −2 до 2, степень от 2 до 16.
- Сетка 3×3, 5×5 или 7×7, по умолчанию 3×3. Щелчок выбирает миниатюру;
  «Исследовать рядом» сужает диапазоны вдвое, «Назад к диапазону» возвращает их.
- «Применить в текущем окне» или двойной щелчок передаёт три компоненты C и степень,
  закрывает атлас и обновляет основной кадр и миниатюру карты выбора C.
  Камера, свет, палитра, итерации, радиус вылета и качество сохраняются.
- Правка фиксированных параметров блокирует прежний выбор до перестроения.
  «Остановить» отменяет расчёт и сохраняет готовые ячейки. Закрытие без применения
  не меняет исходный вид. Числа завершаются через NumericInput; ошибочный ввод
  восстанавливается или ограничивается с объяснением у поля.

Сетка не гарантирует непустоту или связность каждой формы. Изменение степени
меняет геометрию; крайние и отрицательные степени могут давать пустые или сложные виды.

## Реализация

`Views/JuliabulbAtlasWindow.cs` использует общий `Julia3DShapeAtlasWindow`, `Fractal3DParameterAtlasWindow` и
оболочку `ParameterAtlasWindow`. Превью 144×108 считаются последовательно на ГП,
от центральной ячейки, с камерой и оформлением исходного вида. Для миниатюр:
до 32 итераций, до 160 шагов луча, SSAA=1, без AO и мягких теней.
Каждое поколение использует неизменный снимок; старые результаты не заменяют новые.
Неизменённые double-параметры возвращаются без потери точности при преобразовании в decimal.

`Fractal3DWindow.ShapeAtlas.cs` приостанавливает основной цикл и миниатюру
карты на время модального атласа. При закрытии ресурсы освобождаются после завершения
текущего запроса ГП. Используются существующие рендерер, шейдер и его общий кэш.
Формула, пресеты, начальный вид, формат сохранений и облачная категория не меняются.

## Проверка

```powershell
dotnet build .\FractalExplorerWPF\FractalExplorerWPF\FractalExplorerWPF.slnx
dotnet run --project .\FractalExplorerWPF\Verification\SavePreviewVerification.csproj -- juliabulb-atlas
```

Группа проверяет все шесть пар осей, разные границы C/степени, точность, прямой
GPU-кадр, отмену поколений, уточнение/историю, применение только параметров формы,
закрытие и JSON-сохранение. Настоящие пользовательские данные не используются.

Вручную: открыть атлас, сравнить Cx/Cy и степень/Cz; изменить фиксированную C,
уточнить диапазон и вернуться; применить вариант и проверить C, степень и маркер
карты. Повторно открыть, остановить расчёт и закрыть без применения.
