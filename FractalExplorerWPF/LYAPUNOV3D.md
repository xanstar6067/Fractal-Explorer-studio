# Ляпунов 3D

Режим находится в «Динамические системы и хаос → Анализ динамики», а также
в общей подборке «Трёхмерные». Ключ запуска — `Fractal3D:Lyapunov3D`.
Он использует общее окно `Fractal3DWindow`, его камеру, свет, палитры,
сохранения и экспорт с SSAA.

## Математика

Оси куба задают параметры A, B, C. В каждой точке повторяется введённая
последовательность (например, `ABCCAAB`); очередная буква выбирает rₙ:

```text
xₙ₊₁ = rₙ xₙ (1 − xₙ)
λ ≈ (1/N) Σ ln |rₙ (1 − 2xₙ)|
```

Прогрев не входит в сумму. Измерение продолжает фазу последовательности
после прогрева; производная берётся до обновления x. Параметры лежат в
[0, 4], начальное x — внутри (0, 1). Два символа A/B дают точное
вытягивание двумерной карты вдоль C; третий символ добавляет независимый
параметр. Это пространство параметров одномерного отображения.

λ < 0 означает сжатие близких орбит, λ > 0 — их экспоненциальное
расхождение. Нулевая экспонента требует особого внимания: конечное время
наблюдения приближает её, а сходимость вблизи границы может быть медленной.

## Исследование

- Пять видов: области устойчивости `ABCCAAB`, устойчивые острова `ABCBBACC`,
  полоса вокруг λ = 0, прозрачный объём `AABBC` и карта при C = 3,5.
- Последовательность: 1–64 латинских символа A/B/C; пробелы и регистр
  игнорируются. Диапазоны каждой оси задаются отдельно.
- Сетки 32³, 64³, 128³; прогрев 0–4096, измерение 16–4096 итераций.
- «Устойчивость» показывает λ ≤ выбранного уровня, «Хаос» — λ ≥ уровня;
  «Граница» показывает |λ − уровень| ≤ полуширины полосы. При уровне 0
  эти названия соответствуют знаку экспоненты.
- Выбор A/X, B/Y или C/Z отсекает часть куба. Ползунок подписан значением
  соответствующего параметра. «Только цветная плоскость среза» показывает
  карту λ на выбранной плоскости, независимо от выбранной области.
- Общий стиль «Плотность» интегрирует прозрачный объём с окраской по λ;
  остальные восемь стилей используют общую поверхность и освещение.
- Окраска поверхности: λ, A, B, C и общие геометрические источники.
  Диапазон ±λ задаёт шкалу: отрицательный край — начало палитры,
  ноль — середина, положительный край — конец. Срез и прозрачный объём
  всегда показывают экспоненту.

## Вычисление и хранение

`Lyapunov3DComputeShader` считает экспоненту на Direct3D 11 в текстуру
R32_Float на общем устройстве окна. Ячейки соответствуют центрам вокселей.
Каждая команда считает одну плоскость Z; между командами проверяются
отмена и завершение работы GPU. Поле публикуется целиком после расчёта.
При отмене сохраняется предыдущая готовая текстура.

Готовое поле переиспользуется при изменении камеры, света, палитры, стиля,
уровня, области, полосы и среза. Последовательность, диапазоны, начальное x,
число итераций или сетка вызывают новый расчёт. Прогресс поля занимает
первые 60% индикатора, трассировка — оставшиеся 40%.

Поле и трилинейная поверхность являются приближением: детали меньше
вокселя могут исчезнуть. Орбиты считаются в одинарной точности; длительные
хаотические орбиты чувствительны к округлению. Для нулевой производной
логарифм ограничен снизу значением ln(10⁻³⁰), чтобы текстура оставалась
конечной. Это особенно существенно при нулевом прогреве и x₀ = 0,5.

Сохранения — `Saves/Fractal3DLyapunov` через AppPaths. JSON содержит
параметры поля, вид, камеру и палитру; воспроизводимое поле строится снова
при открытии. Сохранения доступны общему облачному репозиторию. Новое
значение `Fractal3DKind` дописано в конец, номера старых режимов сохранены.

Шейдеры `lyapunov3d-field` и `lyapunov3d-pixel` используют общий дисковый
кэш и участвуют в «Пересобрать шейдеры». Превью каталога рендерится в
общей очереди GPU и сохраняется в постоянный PNG-кэш.

## Проверка

```powershell
dotnet build .\FractalExplorerWPF\FractalExplorerWPF\FractalExplorerWPF.slnx
dotnet run --project .\FractalExplorerWPF\Verification\SavePreviewVerification.csproj -- lyapunov3d [папка PNG]
```

Проверка сравнивает независимую double-орбиту с GPU (включая фазу после
нечётного прогрева и последовательность длины 64), проверяет аналитическое
λ = ln|2 − r| устойчивой неподвижной точки, все сетки и вырождение AB,
валидацию, пять видов, девять стилей, все срезы, зонд камеры, переиспользование
поля, отмену во время расчёта, JSON, облачную категорию и фактический кадр
WPF-окна. Пользовательские данные перенаправляются в изолированный каталог.
