# Гироид и периодические поверхности

Пункт **Математические лаборатории → Геометрия и преобразования → Гироид и периодические поверхности** открывает общий исследователь `Fractal3DWindow` с ключом `Fractal3D:PeriodicSurfaces`.

Это тригонометрические (нодальные) приближения, а не точные минимальные поверхности. Формулы взяты из [исследования TPMS, уравнения 2–4](https://doi.org/10.1016/j.jmrt.2024.05.023):

- Gyroid: `F = sin X cos Y + sin Y cos Z + sin Z cos X`.
- Schwarz P: `F = cos X + cos Y + cos Z`.
- Schwarz D: `F = cos X cos Y cos Z − sin X sin Y sin Z`.

Координаты масштабируются: `X = 2πx / (Period · StretchX)`; аналогично Y и Z. Видимая область — куб `[-1,1]³`. При периоде 1 и единичном растяжении по каждой оси помещаются два периода. Уровень задаёт поверхность `F = Level`; растяжение изменяет период отдельно вдоль каждой оси. При ненулевом уровне и растяжении поверхность также не обязана иметь нулевую среднюю кривизну.

Четыре варианта отображения:

- Стенки: `|F − Level| ≤ Thickness / 2`. Толщина выражается в значениях поля F; физическая толщина вдоль стенки меняется.
- Поверхность без толщины: `F = Level`.
- Положительный лабиринт: `F ≥ Level`.
- Отрицательный лабиринт: `F ≤ Level`.

Срез по X, Y или Z оставляет часть с координатой не больше выбранного положения. Стенки и заполненные лабиринты получают закрытую грань среза; поверхность без толщины просто обрезается.

Доступны восемь готовых видов, общие CAD/игровая камера, зонд поверхности, девять стилей освещения, окраска материалом/нормалью/высотой и другими общими источниками, палитры, SSAA, экспорт и автооблёт. Все готовые виды используют CAD-управление с вращением на ЛКМ. Вид «Взгляд вдоль тоннеля» ставит камеру перед входом и показывает всю ячейку; игровой режим для прогулки выбирается вручную в «Навигации». Перед первым кадром показан общий экран подготовки.

Рендер аналитический на Direct3D 11, без объёмной сетки или генерации меша. Для шага луча используется глобальная граница градиента: `2 · |k|` для гироида, `|k|` для Schwarz P/D, где `kᵢ = 2π / (Period · Stretchᵢ)`. Это консервативная оценка, сохраняющая тонкие стенки и работающая в критических точках. Луч изнутри заполненной области идёт до выхода. Нормаль поверхности без толщины вычисляется по самому полю F.

Состояние: `Models/PeriodicSurfaceSettings.cs`; шейдер: `Core/Rendering3D/PeriodicSurfaceShader.cs`; UI: `Views/Fractal3DWindow.PeriodicSurfaces.cs` и общая XAML-разметка. Сохранения — `Saves/Fractal3DPeriodicSurfaces` через AppPaths, доступны в общем облачном менеджере. Байткод `fractal3d-PeriodicSurfaces-pixel` входит в общий дисковый кэш и команду «Пересобрать шейдеры». Превью каталога автоматически рендерится в очереди ГП.

Проверка с изолированными данными:

```powershell
dotnet run --project .\FractalExplorerWPF\Verification\SavePreviewVerification.csproj -- periodic-surfaces [папка PNG]
```

Она проверяет три семейства и четыре области по независимым аналитическим пересечениям лучей, срез, камеру внутри материала, восемь видов, параметры формы, девять стилей, точное сохранение/восстановление, облачную категорию, кэш, ввод/ползунки, первый WPF-кадр и отмену. Группа `shadercache` проверяет включение нового шейдера в пересборку. Группа `catalog` проверяет поиск, превью и порядок новых поступлений.
